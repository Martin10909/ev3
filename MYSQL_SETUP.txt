## 1️⃣ Instalación de MySQL (Windows)

### Opción A: MySQL Community Server (Recomendado)

1. **Descargar:** https://dev.mysql.com/downloads/mysql/
2. **Versión:** MySQL 8.0 Community Server
3. **Instalar:**
   - Next → Next → Next
   - ✅ Marcar: "Add MySQL to PATH"
   - Puerto: **3306** (default)
   - Username: **root**
   - Password: **Tu contraseña** (recuérdala!)

4. **Verificar instalación:**
   ```bash
   mysql --version
   ```

### Opción B: MySQL + Workbench (Bundle)

- Descargar: https://dev.mysql.com/downloads/mysql/
- Seleccionar: "MySQL Installer for Windows"
- Instala MySQL + Workbench automáticamente

## 2️⃣ Configuración de MySQL Workbench

### Crear nueva conexión:

1. **Abre MySQL Workbench**
2. Click en **"Database" → "Manage Connections"**
3. **New** → Llena los campos:
   - **Connection Name:** helpdesk
   - **Connection Method:** Standard TCP/IP
   - **Hostname:** localhost
   - **Port:** 3306
   - **Username:** root
   - **Password:** [Tu contraseña]
4. **Test Connection**
5. **OK**

### Conectar a la BD:

1. En el inicio, haz doble click en la conexión "helpdesk"
2. Se abrirá una ventana con el editor SQL

## 5️⃣ Conexión desde Node.js

### Instalar driver MySQL:

```bash
cd C:\Users\kevin\Downloads\STF\STF
npm install mysql2 dotenv
```

### Crear archivo de conexión:

**Archivo:** `src/data/mysql_connection.js`

```javascript
const mysql = require('mysql2/promise');
require('dotenv').config();

const pool = mysql.createPool({
  host: process.env.DB_HOST || 'localhost',
  port: process.env.DB_PORT || 3306,
  user: process.env.DB_USER || 'root',
  password: process.env.DB_PASSWORD || '',
  database: process.env.DB_NAME || 'helpdesk_db',
  waitForConnections: true,
  connectionLimit: 10,
  queueLimit: 0,
  enableKeepAlive: true,
  keepAliveInitialDelayMs: 0,
});

// Verificar conexión
pool.getConnection()
  .then(conn => {
    console.log('✅ Conectado a MySQL');
    conn.release();
  })
  .catch(err => {
    console.error('❌ Error de conexión:', err.message);
  });

module.exports = pool;
```

## 🆘 Solución de problemas

### "Error: PROTOCOL_CONNECTION_LOST"
```sql
-- En Workbench, ejecutar:
SHOW VARIABLES LIKE 'max_connections';
SET GLOBAL max_connections = 1000;
```

### "Error: Access denied for user 'root'"
- Verificar contraseña en `.env`
- Resetear password de MySQL

### "Error: Database 'helpdesk_db' doesn't exist"
- Ejecutar el script SQL nuevamente en Workbench
- Verificar que no haya errores
