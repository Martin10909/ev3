## 📡 Endpoints Disponibles

### Sin autenticación:
- `POST /api/login` - Iniciar sesión
- `POST /api/logout` - Cerrar sesión

### Con autenticación (Requiere token):
- `POST /api/tickets` - Crear ticket
- `GET /api/tickets` - Listar tickets
- `GET /api/tickets/:id` - Ver ticket específico
- `PUT /api/tickets/:id` - Actualizar ticket
- `DELETE /api/tickets/:id` - Eliminar ticket

## 🧮 Algoritmo de Prioridad (IMPLEMENTADO)

Calcula automáticamente basado en:

| Impacto | Puntos |
|---------|--------|
| bajo    | 1      |
| medio   | 2      |
| alto    | 3      |

| Urgencia | Puntos |
|----------|--------|
| baja     | 1      |
| media    | 2      |
| alta     | 3      |

**Bonificaciones:**
- Categoría "red" o "cuenta": +1
- Tiempo estimado > 4 horas: +1

**Resultado:**
- 1-3: **Baja**
- 4-5: **Media**
- 6: **Alta**
- 7+: **Crítica**

## 🧪 Prueba Rápida con Thunder Client/Postman

### 1. Login
```
POST http://localhost:3000/api/login
Body JSON:
{
  "username": "admin",
  "password": "1234"
}
```

**Guardá el token de la respuesta**

### 2. Crear Ticket
```
POST http://localhost:3000/api/tickets
Headers:
  Authorization: Bearer [TOKEN_AQUI]
Body JSON:
{
  "nombreSolicitante": "Juan Pérez",
  "correo": "juan@email.com",
  "categoria": "red",
  "descripcion": "Red caída",
  "impacto": "alto",
  "urgencia": "alta",
  "tiempoEstimado": 5
}
```

### 3. Ver Tickets
```
GET http://localhost:3000/api/tickets
Headers:
  Authorization: Bearer [TOKEN_AQUI]
```

## 🆘 Solución de Problemas

**Error: "puerto 3000 en uso"**
```bash
# Cambiar puerto en src/app.js:
const PORT = 3001;
```

**Error: "npm no se encuentra"**
```bash
# Usar PowerShell con permisos:
powershell -NoProfile -ExecutionPolicy Bypass
```

**Server se apaga al hacer cambios**
```bash
# Usar nodemon en desarrollo:
npm run dev
```
