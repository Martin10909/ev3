## 🚀 PASOS PARA PONER EN FUNCIONAMIENTO

### **Paso 1: Instalar MySQL**
Si no lo has hecho:
1. Ve a: https://dev.mysql.com/downloads/mysql/
2. Descarga MySQL 8.0 Community Server
3. Instala y marca **"Add to PATH"**
4. Reinicia tu PC

### **Paso 2: Crear la Base de Datos**
1. Abre **MySQL Workbench**
2. Crea una nueva conexión (si no la tienes):
   - Hostname: `localhost`
   - Port: `3306`
   - Username: `root`
   - Password: [tu contraseña o vacío]

3. Copia TODO el contenido de `database_mysql.sql`
4. Pega en una **New Query Tab** en Workbench
5. Ejecuta con `Ctrl + Enter`

**Resultado esperado:**
```
✅ Query OK. Database created.
✅ 12 tables created successfully.
✅ Sample data inserted.
```

### **Paso 3: Configurar variables de entorno**
El archivo `.env` ya está creado. Verifica/actualiza:

```bash
# .env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=          # Déjalo vacío si no tienes contraseña, o coloca la tuya
DB_NAME=helpdesk_db
```

### **Paso 4: Instalar dependencias Node.js**
```bash
cd C:\Users\kevin\Downloads\STF\STF
npm install
```

### **Paso 5: Iniciar el servidor**
```bash
npm start
```

**Deberías ver:**
```
✅ Conectado a MySQL - Base de datos: helpdesk_db
🚀 Servidor ejecutándose en http://localhost:3000
```

### **Paso 6: Probar en el navegador**
1. Abre: **http://localhost:3000**

## ⚠️ Si algo no funciona

### "Error: connect ECONNREFUSED 127.0.0.1:3306"
- MySQL no está ejecutándose
- Solución: Abre MySQL desde Services o reinicia
```bash
net start MySQL80  # En cmd con permisos
```

### "Error: Unknown database 'helpdesk_db'"
- No ejecutaste el script SQL en Workbench
- Solución: Copia `database_mysql.sql` y pégalo en Workbench

### "Error: Access denied for user 'root'"
- Contraseña incorrecta en `.env`
- Solución: Verifica la contraseña en MySQL Workbench

### Las funciones de ticket/auth retornan error
- Probablemente no instalaste las dependencias
- Solución: `npm install`
